# Language-model example source

- `lfm3/` exports staged text-decoder graphs. `lfm/` contains local packing and numerical comparison tools.
- `qwen_dsp.c`, `dsp_qwen.py` and `chat_session.py` implement the native Qwen DSP example and its host session.
- The common HXFG, state and device lease contracts are documented in the maintained guides. [Tensor backend](../../../docs/hexecutor/tensor-backend.md), [dynamic CDSP memory](../../../docs/hexecutor/dynamic-memory.md)
